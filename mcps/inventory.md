# MCPs & External APIs Inventory

Registry of MCPs and external APIs evaluated for this project. Populated during planning.

## Format

| Name | Type | Status | What It Provides | Notes |
|------|------|--------|-----------------|-------|
| mcp-name | MCP / API | selected / rejected / pending | | |

## Type Definitions
- `MCP` — Model Context Protocol server (tool available to the AI during execution)
- `API` — External REST/GraphQL API called by the application at runtime

## Status Definitions
- `selected` — installed/configured and active
- `rejected` — evaluated and not used (document why)
- `pending` — under evaluation

## Registry

(Populated during /init-project planning step — do not skip MCP/API evaluation)

## Notes
Search MCP registries and available environment tools during planning. Do not write "None selected" without exploring first.
