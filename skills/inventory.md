# Skills Inventory

Governed registry of skills evaluated for this project. Populated during planning.

## Format

| Skill | Scope | Status | Notes |
|-------|-------|--------|-------|
| skill-name | base / project | selected / rejected / pending | Reason for status |

## Scope Definitions
- `base` — available in the FactorIA template environment
- `project` — installed specifically for this project

## Status Definitions
- `selected` — installed and active, used in this project
- `rejected` — evaluated and not used (document why)
- `pending` — under evaluation

## Registry

(Populated during /init-project planning step — do not skip skill evaluation)

## Notes
Before creating a new skill: verify no existing skill covers the need. New project-specific skills registered here with scope = project.
